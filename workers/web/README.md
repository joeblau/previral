# Previral landing page

Next.js App Router site deployed with `@opennextjs/cloudflare` (OpenNext) as the
Cloudflare Worker **`blau-previral`**. Run these commands from `workers/web/`.

```sh
npm ci
npm run dev           # Next.js development server, localhost:3000
npm run typecheck
npm run build:worker  # Next.js build + OpenNext Worker bundle
npm run preview       # production build in the local Workers runtime
```

## Deploy

```sh
npx wrangler whoami
# If not authenticated: npx wrangler login
npm run deploy
```

The Worker name and self-reference service binding are set in `wrangler.jsonc`.
The default deployment uses the account's `workers.dev` subdomain. A custom
domain can be added to this file when one is selected. For Cloudflare Workers
Builds, use root directory `workers/web`, build command `npm run build:worker`,
and deploy command `npx opennextjs-cloudflare deploy`.

No database, secrets, R2 bucket, or image optimization service is needed. The
landing page is prerendered, with a small client component for switching between
activity and multimodality illustrations. Fonts and images are served locally.
The OpenNext Worker serves Next.js routes; this is not a static-export or Pages
deployment.

Run `npm run cf-typegen` after changing bindings. Check the deploy bundle with
`npx wrangler deploy --dry-run` after building.

## Visual assets

`public/brain-activity.png` and `public/brain-multimodal.png` are generated by the
app's `apple/Verification/BrainRenderingCheck.swift`, using synthetic fields on
the fsaverage5 cortical surface. They are illustrations, not actual model
predictions from a video. To regenerate them from the repository root:

```sh
make verify-brain
cp apple/build/brain-review/folded.png workers/web/public/brain-activity.png
cp apple/build/brain-review/multimodal-folded.png workers/web/public/brain-multimodal.png
```

The preview's timelines are also synthetic. The primary calls to action link to
source and setup instructions because the app is currently built from source.
